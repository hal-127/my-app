# 育成素材計算機（低ランク換算）

ゲーム（鳴潮など）のキャラクター育成素材について、**段階ごとの「必要数」と「所持数」**を入力すると、

- どの素材が何個足りないか
- 最下段（低ランク）素材に換算して、あと何個必要か

を自動で計算する静的Webアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

1. 「必要数」「所持数」を段階ごとに入力します。
2. 不足数と、最下段素材に換算した必要数が表示されます。
3. 素材グループは「＋ 素材グループを追加」で増やせます（キャラ突破素材・武器素材・スキル素材など）。
4. 「段階設定」から、段階名と変換率を変更できます（2〜6段階）。

入力内容はブラウザの localStorage に自動保存されます。

## 計算ロジック

段階は「低 → 高」の順に並んでいて、下位素材から上位素材を合成できる前提です。

- 「上位段階の不足分」は、合成に必要な数として下位段階に加算されます。
- したがって、最下段の不足数が「あと何個集めればよいか（最下段換算）」になります。
- 上位素材を持ちすぎていても、下位素材には変換できません（合成は下位→上位の一方向）。
- 余剰分は「余剰」として表示されます。

例：段階が「低 ×3 → 中 ×5 → 高 ×3 → 最高」のとき

| 段階 | 必要 | 所持 | 不足 | 補足 |
| --- | --- | --- | --- | --- |
| 低 | 10 | 30 | 13 | 合成込 +33 |
| 中 | 6 | 15 | 11 | 合成込 +20 |
| 高 | 3 | 2 | 4 | 合成込 +3 |
| 最高 | 1 | 0 | 1 | |

このとき「最下段（低）素材であと 13 個」が答えになります。

## 主な機能

- 段階名・変換率のカスタマイズ（プリセット付き）
- 複数の素材グループ管理
- 結果のテキストコピー（メモやチャットへの共有用）
- 自動保存（localStorage）
- レスポンシブ対応（スマホ表示）

## ファイル構成

```
index.html   画面のマークアップ
styles.css   スタイル
app.js       計算・状態管理・描画
```

## 公開する場合

そのまま GitHub Pages / Netlify / Vercel などの静的ホスティングに置くだけで公開できます。

```bash
# ローカルで確認する場合の例（Node.js）
npx serve .
```

## カスタマイズ

`app.js` の `createDefaultState()` を変更すると、初期表示の段階名・変換率・サンプルデータを変えられます。
`TIER_COLORS` を変更すると、段階ごとの色を調整できます。
